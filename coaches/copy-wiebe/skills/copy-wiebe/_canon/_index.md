# /copy-wiebe canon — Table of Contents

This folder holds the reference material for the AIWiebe synthetic
conversion copywriting coach.

One operator: Joanna (Jo) Wiebe — founder of Copyhackers (2011) and
Copy School, original conversion copywriter, author of *The Copyselling
System* (Simon & Schuster, July 2026), the Copy Hackers book series,
10x Landing Pages, 10x Sales Pages, 10x Emails. Trained 70,000+
marketers. Worked with AWS, Canva, Wistia, Buffer, Crazy Egg, Shopify.

Conversion copywriting is NOT direct response (Kennedy / Halbert) and
NOT brand voice. It is research-led, testable, web-native, accountable
to a conversion rate. Wiebe coined the term and built the discipline.

## Files in this folder

### `conversion_copy_3part_process.md`
The 3-part Wiebe process — Research → Write/Wireframe → Test — described
in own words.

- The Research phase (60-80% of the work): VoC mining, the four
  diagnostic questions, the source tier list, Amazon Review Mining
  technique (the Wiebe signature), Google Review Mining shortcut,
  the spreadsheet schema
- The Write/Wireframe phase: the landing-page wireframe order, the
  formulas (PAS deep dive, PAS-on-Steroids extension Why/Try/Buy, BAB,
  FAB), the 4 U's stress test (Masterson, attributed), the button
  copy rule
- The Test phase: A/B vs. ship-and-watch vs. 5-second test vs.
  Wynter-style ICP message test, what to test in priority order, what
  "winning" actually means
- VoC Review Mining process deep dive (9 steps)
- Standing rules / operator vocabulary

**Load for:** any landing page or sales page work, VoC research
questions, formula application (PAS, BAB, FAB), email sequence
construction, message hierarchy questions, "we did the research, now
what" questions, A/B test design.

### `copyhackers_principles.md`
The 12 standing principles drawn from Wiebe's 15-year Copyhackers blog
archive, Tutorial Tuesdays library, and conference corpus.

- Principle 1 — Kill the pixie dust (anti-marketing-speak)
- Principle 2 — Write like a human, convert like a badass
- Principle 3 — The page is qualifying, not just converting
- Principle 4 — The hero does 80% of the conversion work
- Principle 5 — Evidence beats adjectives
- Principle 6 — The Rule of One (One Reader / One Offer / One Promise /
  One Big Idea)
- Principle 7 — Don't write copy. Find it.
- Principle 8 — Match the message to the stage of awareness (Schwartz)
- Principle 9 — Click triggers earn the click
- Principle 10 — Don't polish. Sweep. (The 7 Sweeps deep dive — clarity,
  voice & tone, "so what?", "prove it," friction, specificity, heart)
- Principle 11 — The Tutorial Tuesdays voice (Wiebe's public teaching
  cadence — model this)
- Principle 12 — Headlines that get clicked (the headline approach,
  6 standing rules)
- Summary doctrine: the 10 lines to remember

**Load for:** critique work, voice and tone diagnostics, principle
questions, "what would Joanna actually do" framing, the 7 Sweeps
editing pass, hero section audits, headline writing, the
anti-polishing discipline.

## Loading rules

1. Read `SKILL.md` locally first.
2. Load only the canon file the current question needs. Don't load
   all three unless the user is asking a meta-question across files.
3. Attribute every framework precisely:
   - **Wiebe invented:** conversion copywriting (the term), Amazon
     Review Mining (the technique), 7 Sweeps, BAB, PAS-on-Steroids,
     Copyselling System, Tutorial Tuesdays.
   - **Schwartz invented:** 5 Stages of Awareness (1966).
   - **Masterson invented:** 4 U's headline checklist (AWAI).
   - **Pre-Wiebe (no single attribution):** PAS, FAB, AIDA.
   - When citing — don't blur. Wiebe herself is meticulous about
     attribution; match her standard.
4. For full prose — the Copyhackers blog, Tutorial Tuesdays videos,
   the Copyselling System book, the Copy School curriculum — point the
   user there. This folder is operator-grade summary, not source.
5. Pricing on courses and memberships shifts frequently. If quoting a
   price to Ivan for a buying decision, verify the live page via
   WebSearch before naming the number.

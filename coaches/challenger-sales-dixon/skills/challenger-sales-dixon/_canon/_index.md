## Sourcing standards

**What's in these files:**
- Framework structures (NAMES, STEPS, MECHANISMS, FAILURE MODES) — facts, described in own words
- Book + chapter references for the four Dixon books — so Ivan can read Dixon's own prose
- Short fair-use quotes from Dixon-bylined HBR articles and Dixon-firm-controlled sites, each with URL attribution
- URLs to verified free public sources (HBR archive, DCM Insights, jolteffect.com, dixonspeaks.com, Challenger Inc, major podcast pages)
- Mechanical applications calibrated to DR's business

**What's NOT in these files:**
- Reproduced book paragraphs, chapters, or sections from any of the four Dixon books
- Long verbatim transcript excerpts beyond fair use
- Full reproductions of paywalled HBR article bodies (abstracts only; URLs to publisher pages)
- Pirated PDF / audiobook content from any source

**If Ivan asks for "the actual book chapter":** the answer is buy the book and use `free_authored_articles.md` for the free supplementary content. These files are operator-grade framework maps. Dixon's prose is in his books and his published HBR articles.

## Load policy

Default: load nothing at session start. Load on demand based on the framework→file table above.

If multiple files are needed, load in this order:
1. `_index.md` (this file)
2. The specific framework file (`challenger_sale_frameworks.md` or `jolt_effect_frameworks.md`)
3. `public_corpus_excerpts.md` for voice + verified quote sourcing
4. `free_authored_articles.md` only when surfacing a URL for Ivan to read

Do not load all four files unless explicitly asked to.

# DR Coaches — Quickstart (1 page)

**What this is:** 31 expert advisor "coaches" inside Claude — pricing, copy, CRO, sales, negotiation,
positioning, hiring, ops, and more. Each is a slash command and also answers plain questions.

## Install (Cowork) — once, ~30 seconds
1. Claude Desktop → **Cowork** tab → **Customize** (left sidebar) → **Plugins**.
2. **"+" → Add marketplace** → paste the repo URL your admin gives you (`https://github.com/<org>/dr-coach-packs`).
3. Click **Install** on the four packs → start a new session. Type `/` and you'll see the coaches.

Full install detail + the org-admin auto-install route: see **INSTALL.md**.

**Pack or single coach:** install a whole pack (e.g. `ultimate-coach-pack`) or just one coach (e.g. `negotiation-voss`) — 34 options total.

## Two rules
1. **You don't need all 31.** Learn your 3–4 above. Open the full **COACHES.md** playbook only when you hit a problem outside your lane.
2. **Plain language works too.** "What would Voss do with this objection?" fires the same coach as `/negotiation-voss`.

Stuck on which coach? Open **COACHES.md** → "Router 3 — the overlap calls."

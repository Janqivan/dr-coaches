## Decision tree — when to invoke which

```
Is the problem about WORDS people see?
  ├── Product-level differentiation          → /dunford
  ├── Customer-facing brand story            → /storybrand
  ├── Long-form sales copy / email / VSL     → /copy
  └── Authority content / personal brand     → /priestley

Is the problem about WORDS in a conversation?
  ├── Negotiation / hard talk                → /voss
  └── Outbound prospecting / pipeline         → /sales

Is the problem about MONEY?
  ├── Pricing strategy + offer design         → /mike (services lens) or /martin (strategic lens)
  ├── Profit + cash discipline                → /mike
  ├── Labor productivity + scaling            → /crabtree
  └── Paid media spend efficiency             → /marshall

Is the problem about PEOPLE?
  ├── Hiring decisions                        → /who
  └── Founder time + focus                    → /newport

Is the problem about THE BUSINESS ITSELF?
  ├── Strategic direction / 3-year cascade    → /martin
  ├── Building it to sell / recurring revenue → /warrillow
  └── EOS operational install                 → /eos-coach (separate plugin)
```

## Sourcing standard (what's inside each skill, what's not)

**Each coach is built from:**
- Framework structures described in own words (names, steps, mechanisms, failure modes — these are facts, not copyrightable)
- Short fair-use quotes from the operator's author-owned free public corpus (their own blog, their own podcast, their own YouTube, their own newsletter, their HBR / Forbes columns)
- URLs to verified free public sources where available (each canon file includes the operator's free corpus pointer)
- DR-specific calibration in a locked "Context: The User" section

**No coach contains:**
- Reproduced book chapters or paragraphs (even paraphrased)
- Pirated PDFs / audiobooks from any source
- Long verbatim transcript dumps
- Fabricated "quotes" presented as the operator's words

Each coach's `_canon/` folder includes a framework-summary file (in own words) and either a public-corpus excerpts file or a corpus-pointer index. Where Ivan needs Voss/Dunford/etc.'s actual prose, the skill points him at the book or the operator's own free public content — never reproduces it.

# /copy canon — Table of Contents

This folder holds the reference material for the AICopy synthetic coach.
Two operators, attributed separately. Do NOT blur them.

- **Dan Kennedy** sets the philosophy (70% of the weight). Magnetic
  Marketing, No B.S. Direct Marketing, The Ultimate Sales Letter, No
  B.S. Price Strategy.
- **Stefan Georgi** sets the modern execution (30% of the weight). RMBC
  Method, mechanism-first copywriting, the brief as the work.

## Loading rules

1. Read `SKILL.md` locally first.
2. Load only the canon file the current question needs — never both at
   once unless the user is asking a comparison question.
3. Attribute every framework by operator inline. If a user asks "where
   does the P.S. rule come from?" the answer is Kennedy, not "direct
   response in general".
4. For full prose — Kennedy's books, Georgi's paid RMBC course — point
   the user there. This folder is operator-grade summary, not source.

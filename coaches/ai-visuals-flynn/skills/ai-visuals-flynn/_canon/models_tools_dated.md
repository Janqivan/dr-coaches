### Methods (named or ordered)
#### Four model types and the short-prompt test
- When they use it: sorting any new generator before giving it a job.
- Steps: 1. Give a very short prompt ("woman in the park", "photo of a samurai"). 2. More detail back = creative (Midjourney); less = coherent (Flux, ChatGPT, Imagen: needs direction, gives control). 3. For a coherent model write a long, detailed prompt (LLM-written). 4. Trainable = train a LoRA on a hat; editing = add a knife, sunglasses, a hat (ChatGPT, Gemini, Runway, Flux Context).
- Their example: a stage test of one-word prompts across generators: ChatGPT worst, looked like nothing and stayed bland.
- Sources: [YT:ssxPDDjSVY0, YT:nJI3MR9LZXQ, YT:MzobW5KQEEI] (n.d., 2025-10, 2025-11)

#### New-model testing protocol
- When they use it: any model drop.
- Steps: 1. Treat the drop as marketing. 2. Run a fixed 10-15 prompts. Image: control (long detailed prompt obeyed?), consistency (a can with small text), lots of text, composition. Video: physics (a girl dancing in a room of mirrors, reflections must mimic her), extreme camera motion, speed, edge cases, acting, sound, dialogue. 3. Hit known failure points: stairs, reflections, hands, legs (about a week per release). 4. Retry old failures (exact-hex mood boards). 5. If it fails, drop it at once; if it passes, wait 3-4 weeks before judging.
- Their example: ChatGPT image gen honoured the hex-colour mood board Midjourney could not.
- Sources: [YT:AxV8TR3BdqI, YT:wlsmAeMQNEM, YT:F6P2EAfAwjw] (n.d., 2024-10, 2025-10)

#### Fair A/B on a new Midjourney version
- When they use it: comparing a new version with the old on your own prompts.
- Steps: 1. Copy the seed from the earlier job (e.g. the v6 image). 2. Rerun the exact prompt on the new version with the seed pasted: `--v 6.1 --seed <value>`. 3. Read colour, contrast, texture, hands, text on the same starting noise. 4. Include the standard test prompt: a human face with comic-book illustrations layered on top.
- Their example: v6 vs 6.1; the same prompt plus his P code needed no changes and "shocked me to my core".
- Sources: [YT:wlsmAeMQNEM] (2024-10)

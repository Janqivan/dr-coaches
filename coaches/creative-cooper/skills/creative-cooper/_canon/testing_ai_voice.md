## 2. Frameworks and methods

### 2A. AI production

**F1. 3-step Nano Banana static pipeline (2026, GEN/DTC)** — when: new brand, mass statics. Steps: (1) new Claude chat + "master brand research prompt" (edit only brand name + URL) → Claude writes a brand DNA doc (context only, he doesn't use the doc itself); (2) follow-up prompt: name exact product, attach 1–3 product images, paste a "template prompts" doc of 40 static ad types, ask Claude to turn every template into a brand-specific prompt; (3) pick styles, paste prompts into Higgsfield (Nano Banana 2), generate. Delete the aspect ratio Claude appends; set it in Higgsfield settings. Two Claude Projects speed it up: (a) drop any ad → exact prompt back; (b) brand + URL → all 40 prompts in one pass. Next step: skills + Claude Code delivering "50 ads a week" to Slack. Prompt credit: Will Satorus (Twitter). [YT:ibzfKRRSHhU](2026-03)

**F2. Building your own template prompts (2026)** — give Claude an existing ad output plus an example: "Give me the standardized prompt for this that I can use for any brand"; keep adding every ad type you like until you have your own playbook. [YT:ibzfKRRSHhU](2026-03)

**F3. AI animation ad pipeline (2026)** — (1) Claude project with system instructions + docs (AI animation script examples, long animated-ad style guide, video-model prompt references); (2) master research prompt (change brand name, website, product) → "brand brief" to review before scripting; (3) pick style + script direction; (4) lock angle and script; (5) "Turn this script into Nano Banana prompts."; (6) generate stills in Higgsfield (2–3 versions each, pick best); (7) "Write me the animation prompts"; (8) animate each still in Kling 3.0 as start frame (8 s, 1080p); (9) review clip, tell Claude what's wrong, regenerate. Rules: first image establishes "the world" — reuse it as reference for every later shot or "They'll just look weird."; lock copy/visuals before animating (video costs far more); generate one shot at a time (multi-shot is "hit and miss"). Image step text-only first; if weak add a reference (ad screenshot gets "literally recreated", Pinterest/"Pixar style character") or paste back: "I am getting this. I want it to be more like this. Update the prompt." [YT:A29szOW7YDE](2026-05)
- Styles: Pixar and claymation are the two main ones; sub-formats = multiple talking characters / voiceover only / song as audio. Start with Pixar; claymation is usually one blended continuous story — "think of it through the lens of a movie director". ### 2B. Testing, account structure and creative ops

**F15. Fresh-account setup (2024, DTC)** — testing campaign (sales objective, each concept = own ad set with ~4 variations, broad) + scaling ASC campaign, one ad set of top performers (some clients 50–60 ads, all left on). Goal: test concepts fairly to significance, then scale horizontally/vertically. Exclude existing customers (list, Klaviyo sync, purchasers, site viewers). Attribution: 7-day click 1-day view for newer accounts, 7-day click for most established. Cost caps: separate third campaign; works in some accounts. [YT:qhVdp32ebWM](2024-05)

**F16. Budget math (2024, DTC)** — $80 product, $30 cost, 25% blended costs, 30% margin → ~$25 blended CPA (growth at 15% margin → $37.35). Ad set daily budget = 50 × target CPA ÷ 7 (CPA $40 → $286/day). If unaffordable, test fewer higher-confidence concepts. [YT:qhVdp32ebWM](2024-05)

**F17. Cadence (2024)** — launch Monday/Tuesday, scale strong ones into the weekend, otherwise 3–4 more days; check every 3–4 days: kill, scale to ASC, or leave. When promoting, don't turn it off in testing — raise its ad set 15–20% as a mini scaling campaign (many ads fail in scaling while thriving in testing). [YT:qhVdp32ebWM](2024-05)

**F18. Variation design (2024)** — cover enough ground but know why: 2 visuals × 2 headlines, not four headlines on one visual [YT:qhVdp32ebWM](2024-05). Congruency beats one-variable tests: each headline needs its own image [YT:SmNpVtfIRHw](2024-11). New accounts: test many fast static testimonials/headlines for angles, then take winners to video (~60% of angles don't work) [YT:Z82ehPFBY54](2024-03).

**F19. Repurpose across formats: static ↔ video hook ↔ headline bar ↔ motion [YT:SmNpVtfIRHw](2024-11). Iterate a dominating top spender with below-benchmark CTR to extend shelf life [YT:fls5dwYVY1M](2025-08).

**F22. Persona-led sprint system (2026)** — [YT:79doYBhLLFU](2026-06)
- Allocation: pick e.g. three personas per batch, split 45% / 40% / 15%; sprint spreadsheet plans a month ahead and tags every ad by persona; hypothesis column per ad.
- Underserved-persona audit: persona share of spend vs share of customer voice (surveys, reviews, comments). Example 30% voice vs 18% spend. Ask why: too few ads, ads failed, or super fans who over-review. Bigger gaps matter most.
- Look-back: all concepts last 30/90 days by persona; "What more so matters is that you're tracking ads by persona." [quote src: YT:79doYBhLLFU]
- Recurring cadence: check underserved personas, pull new VOC into master doc, add personas, redo ranking/allocation, circulate. Spend-vs-VOC report delivered on a schedule.
- Monthly sprint review by media buyers: executive summary, what moved, what scaled, winners and scalers, persona signals (hypothesis vs tested vs performed); ~8 sections → 25–30 pages; weekly sprints, monthly reports, personas mostly fixed month to month.

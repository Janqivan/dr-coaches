# /martin canon — table of contents

This folder holds the reference material the AIMartin skill loads
on demand. Don't load everything at once. Pick the file that matches
the question type.

## Files in this folder

### `playing_to_win_frameworks.md`
**Sources:** Playing to Win (Lafley + Martin, HBR Press, 2013) and
A New Way to Think (Martin, HBR Press, 2022).

**Contains:**
- The Strategic Choice Cascade (Q1-Q5) — master frame
- Winning Aspiration (Q1) — what does winning look like
- Where to Play (Q2) — the arena choice and exclusions
- How to Win (Q3) — the unique value proposition
- Capabilities (Q4) — the activity system
- Management Systems (Q5) — what makes the choices stick
- The Strategy Logic Flow (4-step coherence test)
- Possibility-Based Problem-Solving / "What would have to be true?"
- Strategy ≠ Planning (the comfort-test diagnostic)
- Operational Effectiveness ≠ Strategy (the same-game trap)
- Customers ≠ Shareholders (Fixing the Game restatement)
- Integrative Thinking / The Opposable Mind (4-step move)

**Load this file for:** any cascade work, V/TO pressure-test, hero-niche
commitment, 3-Year Path A/B/C resolution, strategy-vs-planning
diagnosis, integrative-thinking work, possibility-based decisions.

---

### `new_way_to_think_frameworks.md`
**Sources:** A New Way to Think — Your Guide to Superior Management
Effectiveness (Martin, HBR Press, 2022).

**Contains the 10 highest-leverage of Martin's 14 dominant-model
critiques:**
- Competition (Ch 1) — choose a different game, don't be best at the same one
- Stakeholders (Ch 2) — customer first, not shareholder first
- Customers (Ch 3) — loyalty over satisfaction
- Data (Ch 5) — data describes the past, not the choice
- Culture (Ch 6) — change behaviours; culture follows
- Knowledge work (Ch 7) — measure the decision, not the hours
- Corporate functions (Ch 8) — functions serve strategy, not their own efficiency
- Planning (Ch 9) — plan as trailhead, not destination
- Execution (Ch 10) — execution IS strategy in motion
- Talent (Ch 11) — feeling special beats pay
- Innovation (Ch 12) — design the intervention, not just the product
- Capital investment (Ch 13) — value resets at embedment

**Load this file for:** any operator question that's actually about a
broken management model (not the strategy itself). Use for culture
work, talent decisions, planning vs strategy, execution complaints,
capital-allocation pushback, "we're data-rich but choice-poor."

### `when_more_is_not_better_frameworks.md`
**Sources:** When More Is Not Better — Overcoming America's Obsession
with Economic Efficiency (Martin, HBR Press, 2020).

**Contains:**
- The Machine Model vs The Complex Adaptive System Model
- Efficiency vs Resilience Trade-Off (the fragility check)
- Productive Friction (which friction to keep, which to kill)
- Pressure vs Friction Balance
- Perfection vs Improvement
- The Pareto / Power-Law Trap (manage outliers, not means)
- Gross Domestic Friction / the hidden cost in revenue-only metrics
- Connectedness vs Separation Balance (firewall design)

**Load this file for:** any question about system design, fragility,
resilience, optimisation side-effects, "we optimised X and now Y is
breaking," supply-chain risk, single-point-of-failure analysis,
operator-burnout from over-efficiency.

### `opposable_mind_design_of_business_frameworks.md`
**Sources:** The Opposable Mind (Martin, HBR Press, 2007) + The
Design of Business (Martin, HBR Press, 2009).

**Contains:**
- The Opposable Mind (definition + metaphor)
- The Four-Step Integrative Thinking Process (Salience → Causality →
  Architecture → Resolution)
- The Personal Knowledge System (Stance, Tools, Experiences)
- When NOT to use integrative thinking (the cost-benefit test)
- The Knowledge Funnel (Mystery → Heuristic → Algorithm)
- The Funnel as Direction of Travel (codification vs exploration cycle)
- Reliability vs Validity Trade-Off
- Design Thinking as a Business Process
- Abductive Logic (the logic of what might be)
- The Innovation-to-Operation Hand-off (where corporate innovation dies)

**Load this file for:** cognition / decision-making questions, binary
breaks where two options are equally defensible, R&D-to-ops hand-offs,
"we figured out the formula but it broke when we tried to scale,"
productisation of services, design thinking, the moment Ivan needs to
hold two opposed strategic options instead of collapsing to one.

## Loading order — when multiple files apply

1. **Default first load:** `playing_to_win_frameworks.md`. Covers
   ~90% of operator strategy questions on its own.
2. **Add `new_way_to_think_frameworks.md`** when the question is
   actually about a broken management model (culture, talent, data,
   execution, planning) rather than strategy itself.
3. **Add `when_more_is_not_better_frameworks.md`** when the issue is
   about system fragility, optimisation side-effects, or resilience
   trade-offs.
4. **Add `opposable_mind_design_of_business_frameworks.md`** when the
   issue is cognition (binary breaks) or knowledge-funnel work
   (productisation, scaling, R&D-to-ops).
5. **Add `public_corpus_index.md`** when output must cite Martin's
   own prose or hand Ivan a URL to send to a client.

**Rule:** load the minimum that answers the question. Don't load all
five files for a single question — it's wasteful and dilutes the
framework focus.

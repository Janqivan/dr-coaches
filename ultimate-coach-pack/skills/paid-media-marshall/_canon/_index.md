# /marshall canon — index

Reference files for the AIMarshall synthetic-coach skill. Load on demand, one file at a time, based on the question type. Do NOT load everything up front.

## Files in this folder

### `eighty_twenty_frameworks.md`
Framework structures from Perry Marshall's core books and newsletter:
- *80/20 Sales and Marketing* (Entrepreneur Press, 2013)
- *Ultimate Guide to Google Ads* (6th ed., with Bryan Todd + Mike Rhodes)
- *Ultimate Guide to Facebook Advertising* (4th ed., with Bob Regnerus + Thomas Meloche)
- *Memos from the Head Office* (2022)
- The Marketing Letter (perrymarshall.com weekly newsletter)

Frameworks covered:
1. The 80/20 Power Curve (fractal Pareto — 80/20, 80/20², 80/20³)
2. DRT — Desperate, Reachable, Targeted (Five Power Disqualifiers)
3. The Bleeding Neck Test (market-entry filter)
4. The Star Principle (after Richard Koch — #1 in a growing market)
5. Marketing DNA (Specialist/Generalist × Sayer/Doer × Caretaker/Hunter)
6. The Renaissance Club / Network-Density Model
7. Google Ads Relevance Triangle (Quality Score mechanics)
8. Meta Audience-Stack Model (incl. special-ad-category caveat)
9. Customer-Level Testing (the highest-leverage A/B layer)

**Load this for:** framework deep-dives, diagnostic decisions, prep work on campaigns / clients / niches / business-level Pareto cuts.

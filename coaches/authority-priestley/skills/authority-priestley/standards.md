This file is the bar. Every plan, offer, campaign or verdict the coach produces or judges is graded against the checks for its task type. A check is PASS only with evidence pointed at the work itself (a named asset, a date, a number, a cap). "Sounds strategic" is not evidence. State the evidence type next to each verdict.

Scoring: count PASS / total for the task type. Deliver only at >= 85% with zero FAIL on checks marked ★. Otherwise fix and regrade (max 2 loops), then deliver with the remaining FAILs listed honestly.

Canon shorthand: KPI = key_person_of_influence_frameworks.md, OVS = oversubscribed_frameworks.md, A24 = twenty_four_assets_frameworks.md, ER = entrepreneur_revolution_frameworks.md, PCI = public_corpus_index.md, SKILL = SKILL.md.

Canon tensions to respect when grading (do not "fix" them silently; state which version the output uses):
1. 24-asset structure. SKILL.md and KPI Framework 5 describe an 8-column (Brand, Marketing, Sales, IP, Product, Operations, Financial, Team) x 3-row (Public / Private / Productized) matrix. A24 (the deeper book map) describes 4 quadrants (Intellectual, Brand, System, Customer/Community/Cash) x 6 assets. An asset audit PASSES either way only if it names which structure it uses and walks all 24 boxes in that structure.
2. Campaign phases. SKILL and KPI Framework 4: pre 4-6 weeks, window 1-2 weeks, post 2-3 weeks. OVS Framework 6: signals of intent 4-8 weeks, build-up 2-4 weeks, window 1-2 weeks, post 2-4 weeks. A campaign plan PASSES if its durations fall inside one of the two stated ranges and it says which.
3. Outbound. SKILL says never recommend "more outbound" when the answer is one good campaign. Ivan is building outbound infrastructure. Follow SKILL Rule 2: state the objection once, then execute and flag the disagreement on the record.

## 2. Frameworks and methods

### A. AI static workflows

#### Nano Banana 2 static pipeline: Claude + Higgsfield (Cooper, 2026-03)
- When: volume statics for testing; "hundreds of ads" [quote src: YT:_FMXAlfgYQo] on ~$50/month in 1–2 weeks.
- Steps: 1. New Claude chat, run the "master brand research prompt" [quote src: YT:ibzfKRRSHhU] (edit brand + URL) → brand DNA doc, context only. 2. Name the exact product, attach 1–3 product images. 3. Paste a "template prompts" doc of 40 static types; Claude makes each brand-specific. 4. Run chosen prompts in Higgsfield (Nano Banana 2); delete Claude's appended aspect ratio and set it in Higgsfield. 5. New template from any ad: "Give me the standardized prompt for this that I can use for any brand" [quote src: YT:ibzfKRRSHhU].
- Their example: older generators needed 3–4 tries per hit; NB2 made 90–95% of the 40 usable, even with label text. Hott found some of the 40 "just not relevant" [quote src: YT:mpj0A4Prxu4] (2026-04).
- Sources: [YT:ibzfKRRSHhU] (2026-03), [YT:mpj0A4Prxu4] (2026-04) · NOW · DTC/GEN

#### Clone-a-static with JSON prompts (Cottrell, 2026-04 → 2026-06)
- When: turning a proven layout from Foreplay or an ad library into a brand's static.
- Steps: 1. Give Claude the ad: "write me a prompt that will generate the same layout" [quote src: YT:KlhBwk1kmzI] "but for a product of my choice" [quote src: YT:KlhBwk1kmzI], with copy and color slots, a product-image input, one brand color, product accuracy stressed (2026-04). 2. Or his free custom GPT: paste the ad, answer its questions, add a product photo and dictated changes → JSON prompt ("just a better version of a text prompt" [quote src: YT:QKRd7FTZ7vM]) → Nano Banana Pro (2026-05). 3. Brief like a designer: "write me a JSON prompt for a static ad" [quote src: YT:SJi5todbhJg] with headline, hand holding the product, a real review, five-star graphic, CTA "order now", plus "Ask me any questions to help write the prompt." [quote src: YT:SJi5todbhJg] (2026-06).
- Their example: socks static, alpaca swapped for a cartoon duck saying "I love these socks" [quote src: YT:QKRd7FTZ7vM], copy "Cooler than ice, more colorful than a rainbow, softer than silk" [quote src: YT:QKRd7FTZ7vM] (2026-05).
- Sources: [YT:KlhBwk1kmzI, YT:QKRd7FTZ7vM, YT:SJi5todbhJg, YT:cvk-SxErSF8] · NOW · DTC

### C. AI animation and character ads

Animate each still as the start frame in Kling 3.0 (8 s, 1080p, one shot at a time). 9. Tell Claude what's wrong; regenerate.

### D. LLM workflows for research, briefs and copy

#### Evidence discipline (Levinger, 2026-09)
- When: nearly every research or persona prompt, since LLMs fill gaps with "plausible nonsense".
- Steps: 1. Label each claim OBSERVED (exact phrase + source snippet), INFERRED (grounded) or UNSUPPORTED (delete). 2. Avatar role-play: first person, only the provided research; if unsupported, drop character and say data is missing. 3. Don't invent a persona ("That's backwards"): feed raw data, ask it to "find the recurring moments when people enter this category" [quote src: YT:in1l2TPFc1c], "What was happening right before they looked for a solution?" [quote src: YT:in1l2TPFc1c], past attempts, then "rank these moments on how strongly the evidence support them" [quote src: YT:in1l2TPFc1c]. 4. Don't ask "write 10 ads for this persona" [quote src: YT:in1l2TPFc1c]: hold one insight ("it's 3:00 a.m., she can't sleep, she's staring at the ceiling" [quote src: YT:in1l2TPFc1c]) and vary only tone: blunt, curious, humorous, clinical.
- Sources: [YT:in1l2TPFc1c] · NOW · GEN

#### Review analysis and personas (Denney, Cooper, 2026-06/07)
- Denney: upload reviews and ask for strengths and weaknesses, top objections, how they compare with the reputation analysis, trends across golden-nugget phrases, and the trigger points that make someone buy; persona discovery = review CSV + reputation analysis + internal PDF → a deck the team reviews together. One Claude project per client for briefing, hooks and brainstorming; no fully AI briefs or scripts, "a heavy hand" adapts them to creators. [YT:yRgPbqywUJ8, YT:-E9sjb2msjo]
- Cooper: persona prompts show counts analyzed (e.g. 6,000 reviews, 9,000 comments), proof quotes, what was left out, and a "confidence check" flagging inference-heavy sections; run the same prompt in Claude and Parker, paste each output into the other ("What are your opinions on this?") and merge.

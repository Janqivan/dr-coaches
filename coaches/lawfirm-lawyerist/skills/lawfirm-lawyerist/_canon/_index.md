# Canon Index — lawfirm-lawyerist

Routing reference for the Glover-Everett synthetic coach. Use this to
decide which canon file to load for a given user question.

---

## Files in this canon

1. **`small_firm_roadmap_methodology.md`** — Strategy / stage / owner role
2. **`lawfirm_intake_operations_frameworks.md`** — Intake / pricing / team / systems
3. **`lawyerist_public_corpus.md`** — URLs, citations, recommended purchases
4. **`_index.md`** — this file

---

## Routing rules

### Load `small_firm_roadmap_methodology.md` when the user asks about:

- "What stage is my firm?" / stage diagnosis
- The Small Firm Roadmap / the Roadmap book / the Healthy Firm framework
- The six focus areas (strategy, finances, team, client experience,
  systems, owner sustainability)
- The four stages (Launch, Grow, Scale, Mature)
- Entrepreneur / Manager / Technician roles
- "Lawyer-CEO mindset" / owner is the bottleneck / owner stuck in
  technician mode
- Client-centered vs lawyer-centered firm
- The five essential traits (intentional, entrepreneurial, empathetic,
  self-aware, adaptable)
- Niche / positioning at the strategy level
- Owner sustainability / burnout / "I'm doing too much"
- "Is my firm healthy?"

### Load `lawfirm_intake_operations_frameworks.md` when the user asks about:

- Intake / lead conversion / speed-to-lead
- Consultation booking / show rate / engagement letter signing
- Pricing model choice (hourly / flat fee / value-based / subscription)
- Alternative fee arrangements / billable hour replacement
- Service tier ladder design
- Hiring / first-hire-order / scorecards / core values in hiring
- Accountability chart / org structure
- Documented processes / SOPs / operations manual
- Tech stack / practice management software / AI for law firms
- Meeting cadence / weekly team meeting / quarterly planning
- KPIs / dashboards
- Marketing-to-intake handoff / agency-firm interface
- "My ad spend is wasted" (almost always an intake problem)
- "Cost per signed matter" / "cost per signed retainer"

### Load `lawyerist_public_corpus.md` when:

- User asks for a specific resource, URL, podcast episode, or article
- User asks who Stephanie Everett or Sam Glover is
- User wants to verify a claim against source material
- User wants the Lab pricing or to evaluate the Lab program
- User wants the book recommendation or the Scorecard link
- You need to attribute a quote
- User asks about conferences (TECHSHOW, ClioCon, LabCon / TBD Law)

## Compose patterns

Most diagnostics will use TWO files:

- **Strategy / stage / mindset question** →
  `small_firm_roadmap_methodology.md` + `lawyerist_public_corpus.md` for
  citation

- **Intake / pricing / hiring / operations question** →
  `lawfirm_intake_operations_frameworks.md` + `small_firm_roadmap_methodology.md`
  for stage-appropriate framing

- **Full firm diagnostic** (rare, but happens when user pastes a
  full firm profile and asks "what should I work on?") → load all three

---

## Quote and citation rules

- All public quotes must be <15 words and must include the source URL.
- Use the quote-safe fragments in section 8 of `lawyerist_public_corpus.md`
  when you need to attribute.
- Paraphrase the rest. The synthetic coach speaks in its own words.

---

## Voice routing

When the diagnostic leans:

- **Strategic, big-picture, mission-level** → lean Glover
  ("the future of small firm law practice", "client-centered design",
  "the legacy form is dying", systems and automation as principles)

- **Operational, this-quarter, what-do-I-do-Monday** → lean Everett
  ("here's what I'd do this week", "your firm is stuck because the
  owner is the bottleneck", "quarterly planning", "Lab strategist would
  say", "$20/hour work vs $500/hour work")

Most responses blend both. When in doubt, lean Everett — she is the
current operating voice of Lawyerist and the diagnostic is almost
always operational.

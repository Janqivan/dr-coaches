## Quick-Triage Questions

Before loading any canon file, run the SKILL.md diagnostic (5 questions):

1. Have you answered the Big 5 on your site?
2. Are sales reps doing Assignment Selling?
3. Do you have a content manager in-house?
4. Is real video of your team on the site?
5. What are you afraid to publish?

The diagnostic answers tell you which canon file to load next.

## Loading Patterns

**Strategy / philosophy / "should we do TAYA" questions:**
Load `they_ask_you_answer_methodology.md` only.

**Content planning / "what should we write next" questions:**
Load `big_5_and_selling_7_frameworks.md` only.

**Full implementation (CEO wants the whole picture):**
Load BOTH `they_ask_you_answer_methodology.md` AND
`big_5_and_selling_7_frameworks.md`.

**"Where can I learn more / what should I buy" questions:**
Load `sheridan_public_corpus.md` only.

Never load all three unless explicitly asked for the complete picture.

# DR Coach Packs (v3)

A synthetic mastermind circle: real operators rebuilt from their own transcripts as coaches. Each one has a persona, a quality standard and a searchable record. Each one advises the way the real person would, inside their sphere of genius.

- **Claude:** read [CLAUDE.md](CLAUDE.md). It covers what the coaches are, their purpose, how to install them and the rules for using them.
- **Install:** add the marketplace `https://github.com/Janqivan/dr-coaches` (Cowork: Customize → Plugins → Add marketplace; Claude Code: `/plugin marketplace add Janqivan/dr-coaches`).
- **Catalog:** `.claude-plugin/marketplace.json` lists 4 packs and 45 single coaches.

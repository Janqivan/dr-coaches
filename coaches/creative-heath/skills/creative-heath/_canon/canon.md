## 3. Frameworks and methods

**F1. "Match the size of the ask with the complexity of the offer" (format selection)** — when: choosing format for any offer. Steps: (1) size the ask (time, money, trust); (2) small ask → image (conveys everything fast; a 3-minute video loses buyers before the CTA); medium → carousel/slideshow; big ask → video, longer, with proof, testimonials, upside — the drop-off is acceptable because those lost wouldn't buy a big ask anyway; (3) still test the opposite format occasionally; (4) minimum: a series of videos and a series of images, carousel later on the optimisation calendar. Example: $12 novelty sunglasses = image only; brand-new products/complex services = video only. — [YT:HzDJpKu7vew] (2020-07), [YT:N3X8CuD_VQk] (2023-02), [YT:GPp8Y-lKzJw] (2025-02)

**F2. Testing order (2026)** — when: deciding what to test next. (1) offer, (2) angle (one per ad), (3) creative style (UGC / influencer / founder-led / demo / testimonial / animation), (4) hooks, (5) small variables (primary text, headline, background colour, CTA) — often never reached. Initial rounds test big differences without Meta's tool; use the creative testing tool for finer detail where "often the winning happens". — [YT:8dJxOaZrK1M] (2026-03), [YT:onFwSud9C2Y] (2026-02)

**F3. 10-hooks creator method** — when: producing video with a creator or yourself. (1) Brief 1–2 full 30–60s bodies; (2) record ~10 visual hooks: same or slightly changed opening line(s) in different locations, backgrounds, camera angles, clothing, lighting, phone-selfie vs camera (minutes, under an hour); (3) 10 hooks × 2 bodies = 20 ads for roughly the price of 3; (4) test hooks via creative testing tool; (5) winner goes into the ad set beside very different ads (UGC vs founder vs demo). Rationale: 95% never pass the hook, so We don't really need to change the rest of the ad. Insurance: at least one or two hooks will land. — [YT:IRyR9PzSnM8] (2025-09), [YT:onFwSud9C2Y] (2026-02)

**F4. Hook-rate diagnosis + "Frankenstein" splice** — (1) Customize columns → custom metric "hook rate" = 3-second video plays ÷ impressions, as %; place next to results, sort high→low; (2) read against CPA/ROAS: good hook + poor CPA = body fails; low hook + great CPA = strong body; (3) splice the best hook onto the best body; (4) only pair hooks and bodies that make sense; repeat regularly. Judge hook rates vs account average. — [YT:bAo6SICFyIE] (2026-03)

**F5. Testing + scaling campaign structure (2025–26)** — two campaigns (testing, scaling), one ad set each, same audience (cold + warm mix, open or near-open targeting; Meta blends anyway); separate ad sets only for location. Testing forces spend onto new creative; winners move to scaling. Budget: up to ~80% scaling when profitable, mostly testing when not. Audit fix for a sprawling account: one testing + one scaling campaign, kill awareness/traffic campaigns, campaigns per product range not per product. — [YT:D6Sxk8Mbkq4] (2025-05), [YT:IRyR9PzSnM8] (2025-09)

**F6. Creative testing loop (2021)** — (1) pause underperformers; (2) keep winners live (never pause them to test — results "drop off a cliff"); (3) duplicate a winner and swap in new creative as new ads (e.g. ads 5 and 6 across all ad sets); (4) run ~7 days, longer on small budget; (5) compare cost per result, pause losers, add 2 more; repeat. Max ~5 live ads per ad set. Never edit a live ad — duplicate. Same loop for headlines and primary text. Over 3–6 months has cut cost per purchase 80%; ask why a winner worked and build lookalike ads. Structure then: 1 campaign, 4 ad sets (testing targeting), same 4 ads in each = 16 ads. — [YT:dwUxmlgWfxQ] (2021-03)

**F7. Format-mix launch (2020)** — new ad set with 3–4 ads, one per format (video, image, slideshow, carousel); run ~a week (often visible in 3–4 days); keep winning formats, iterate headline/copy/video inside them. Pause a format only if far worse (40–50% higher CPA); within ~10–20% leave it on. "Methodical traditional" variant: week 1 formats, week 2 four headlines, week 3 four primary texts. — [YT:HzDJpKu7vew] (2020-07), [YT:sxQwH4kjGW4] (2021-03)

**F8. Creative testing tool (Ads Manager, ad level)** — compare 2–5 versions, set budget share, default 7 days (extend for enough conversions), change metric from cost per post engagement to cost per lead/sale; if Meta warns the key metric changed due to budget/duration, raise budget, time or both; afterwards check Meta shifted spend to the winner and turn off the loser. Use it for text overlays rather than guessing. — [YT:onFwSud9C2Y] (2026-02)

**F9. Proof proof proof** — proof types: (1) testimonials (written/video), (2) results images/videos (account screenshots; dating = couple/wedding photos; growth = headcount 6 to 50), (3) photos of work (luxury kitchens — compilation of short clips), (4) transformations (sequential in video; split before/after of bodies gets disapproved). Proof share 25% → 80–90% of runtime. If offer understood → proof-only + copy explains; if not → append offer info. — [YT:z3LiJ0PbY-0] (2024-10)

**F10. Reasons-why-people-buy list** — ~10-minute pre-writing exercise with clients; list every reason incl. social status, then put that reason in ad and sales page. Examples: cakes (delicious, indulgent, low calorie, gift, status); dog walking (save time, avoid stress, avoid guilt, avoid getting wet/cold); interior design (stress-free, beautiful home, impress friends, cozy, feel important); men's shoes (no blisters, last long, price, look good, status); tumble dryer = time with family. — [YT:E0lbvr71wR8] (2020-07), [YT:KgO_J6pwv9I] (2023-09)

**F11. Build order vs viewing order** — users see creative → headline → primary text; build headline (states offer) → primary text (supports headline) → creative last. — [YT:KgO_J6pwv9I] (2023-09)

**F12. Copy technique lists** — 2021 seven: call-out, make clear what you're advertising, offer above "See more", as long as needed no longer, questions at the start, avoid testimonials in copy, benefit-rich. 2023 five (primary text): call-out, benefit-rich, right tone, CTA at the end, shorter usually better. 2019 "five-part Facebook ad template" (lead magnet): offer, image, copy, headline/CTA button, newsfeed link description. — [YT:WeQrKeAwZDg] (2019-07), [YT:1EQrp8MJRek] (2021-01), [YT:KgO_J6pwv9I] (2023-09)

**F13. Call-out method** — open with a question naming the prospect's situation so the right scroller thinks "that's me"; follow immediately with benefits. Variants: life moments (moving/redecorating), location ("West Londoners", "Bristolians", "Texans, check this out"), modified call-out ("Ever used a personal trainer?" aims at people who have NOT). Feeds Meta's ML through engagement signals, especially with broad targeting. Don't stuff every technique into one ad. — [YT:WeQrKeAwZDg] (2019-07), [YT:1EQrp8MJRek] (2021-01), [YT:KgO_J6pwv9I] (2023-09)

Ignore competitors whose ads are all weeks old (Nike) — recheck monthly. Check country pages (amazon.com shows 0 UK results). Pitfalls (2025): big brands' ads often uncopiable; copying too closely breaks voice; shared audiences notice; the hook is already seen. — [YT:4mZ3F77dNdI] (2022-02), [YT:M2VReAjHiN8] (2025-10)
